# Style Guide for The Self-Healing Journey

## Markdown Formatting

### Headers
- Chapter titles: # (H1)
- Major sections: ## (H2)
- Subsections: ### (H3)
- Exercise titles: #### (H4)

### Special Elements

#### Images
```markdown
![Alt Text: Descriptive text]{.kdp-image-full}
```

#### Callouts
```markdown
> **💡 Pro Tip**: Tips and insights
> **💗 Remember**: Emotional support
> **⚡ Quick Note**: Brief information
> **🌟 Personality Note**: Type-specific guidance
```

#### Exercise Boxes
```markdown
```exercise
Title: Exercise Name
Duration: XX minutes
Materials: What you need
```
```

#### Journal Prompts
```markdown
```journal
Your prompt here...
___________________
```
```

### Personality-Specific Content

#### Element Markers
- 🔥 Fire Element
- 🌍 Earth Element
- 💨 Air Element
- 💧 Water Element

#### Type-Specific Instructions
```markdown
### For [Type] Types
- Point 1
- Point 2
- Point 3
```

### Progress Tracking
```markdown
```progress
Date: _________________
Progress: ______________
Next Step: _____________
```
```

## Content Guidelines

### Voice and Tone
- Warm and supportive
- Professional but accessible
- Evidence-based yet engaging
- Inclusive and respectful

### Language Use
- Gender-neutral language
- Clear, concise sentences
- Active voice preferred
- Technical terms explained simply

### Exercise Structure
1. Overview/Introduction
2. Materials/Preparation
3. Step-by-step instructions
4. Personality modifications
5. Progress tracking
6. Integration tips

### Page Layout

#### Front Matter
```markdown
---
title: "Page Title"
chapter: X
section: Y
layout: type
personality_elements: ["element1", "element2"]
techniques: ["technique1", "technique2"]
themes: ["theme1", "theme2"]
duration: "XX minutes"
---
```

#### Body Structure
1. Title and overview
2. Main content
3. Exercise/practice
4. Personality adaptations
5. Progress tracking
6. Integration notes

### Common Elements

#### Lists
- Use bullet points for general lists
- Use numbers for sequential steps
- Use checkboxes for task lists

#### Tables
```markdown
| Column 1 | Column 2 | Column 3 |
|----------|----------|----------|
| Data     | Data     | Data     |
```

#### Code Blocks
Use for structured input areas:
```markdown
```input
Your text here...
```
```

## EPUB-Specific Formatting

### Page Breaks
Add at end of each chapter:
```markdown
{:.kdp-page-break}
```

### Images
- Resolution: 300dpi
- Format: JPG
- Max width: 1200px
- Include alt text

### Navigation
- Include chapter links
- Use consistent heading structure
- Add section markers

## Accessibility Guidelines

### Text
- Use sufficient contrast
- Maintain readable font size
- Include alt text for images
- Use semantic markup

### Structure
- Logical heading hierarchy
- Clear navigation paths
- Consistent formatting
- Descriptive links

## Quality Checklist

### Before Submission
- [ ] Spell check completed
- [ ] Grammar verified
- [ ] Links tested
- [ ] Images optimized
- [ ] Formatting consistent
- [ ] Headings structured
- [ ] Metadata complete
- [ ] Accessibility verified

*This style guide ensures consistent formatting across all book content and optimal display in both EPUB and print formats.*
